# Todo App (static)

This repository branch contains a small single-page Todo application (HTML/CSS/JS) that stores todos in browser localStorage. It's intentionally minimal so you can run it without a build step.

How to run
- Open `index.html` in a browser (double-click or serve the folder with a static server).
- Add, edit, complete, delete todos. Data is persisted in localStorage.

Files added
- `index.html` — SPA UI
- `styles.css` — basic styling
- `app.js` — app logic (localStorage)
- `.gitignore` — ignore editor files, node_modules, etc.
